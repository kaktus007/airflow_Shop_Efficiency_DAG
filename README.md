## 📖 Описание проекта

**Shop Efficiency DAG** — это ETL-пайплайн на Apache Airflow, который автоматизирует процесс загрузки данных о магазинах и расчета ключевых метрик эффективности.

### ✨ Возможности
- 📥 Автоматическая загрузка данных из CSV в PostgreSQL
- 🧮 Расчет эффективности магазинов по уникальной формуле
- 📊 Создание витрины данных для аналитики
- 🏷️ Категоризация магазинов по рейтингу посещаемости
- 📈 Детальное логирование каждого этапа

### Схема базы данных `bd_shops`

#### Таблица `shops` (Магазины)
| Колонка | Тип | Ограничение | Описание |
|---------|-----|-------------|----------|
| `id` | `INTEGER` | `PRIMARY KEY` | Уникальный идентификатор магазина |
| `market_name` | `VARCHAR` | `NOT NULL` | Название магазина |
| `square` | `FLOAT` | `NOT NULL` | Площадь магазина (м²) |
| `city` | `VARCHAR` | `NOT NULL` | Город расположения |

#### Таблица `employers` (Сотрудники)
| Колонка | Тип | Ограничение | Описание |
|---------|-----|-------------|----------|
| `id` | `INTEGER` | `PRIMARY KEY` | Уникальный ID сотрудника |
| `shop_id` | `INTEGER` | `FOREIGN KEY → shops.id` | ID магазина |
| `name` | `VARCHAR` | `NOT NULL` | Имя сотрудника |

#### Таблица `visits` (Посещения)
| Колонка | Тип | Ограничение | Описание |
|---------|-----|-------------|----------|
| `id` | `INTEGER` | `PRIMARY KEY` | Уникальный ID посещения |
| `shop_id` | `INTEGER` | `FOREIGN KEY → shops.id` | ID магазина |
| `visit_date` | `DATE` | `NOT NULL` | Дата посещения |

## 📊 Метрика эффективности

### Формула расчета
efficiency = (площадь / количество сотрудников) * количество посещений


**Где:**
- `square` — площадь магазина (м²)
- `employers_count` — количество сотрудников
- `visits_count` — количество посещений

### Система рейтингов

| Количество посещений | Рейтинг | Эмодзи |
|---------------------|---------|--------|
| > 100 | Отлично | ⭐ |
| 50 - 100 | Хорошо | 👍 |
| 10 - 49 | Средне | 👌 |
| < 10 | Плохо | ⚠️ |

### Граф выполнения
load_data → create_mart → log_success


### Детальное описание задач

#### 1️⃣ **load_data** — Загрузка данных

**Назначение:** Загрузка новых магазинов из CSV в таблицу `shops`

**Алгоритм:**
1. Поиск CSV-файла в директориях:
   - `/opt/airflow/dags/data/new_shops.csv`
   - `/opt/airflow/data/new_shops.csv`
2. Чтение данных через pandas
3. Подключение к PostgreSQL через `PostgresHook`
4. Проверка существования таблицы `bd_shops.shops`
5. Загрузка с `ON CONFLICT DO UPDATE`
6. Возврат статистики через XCom

**Возвращаемые данные:**
```python
{
    'success': 10,        # успешно загружено
    'errors': 0,          # ошибки загрузки
    'total_in_db': 49     # всего в БД
}
```

#### 2️⃣ **create_mart** — Расчет эффективности
**Назначение:** Создание витрины с расчетом эффективности магазинов

**Что делает:**

1. Создает схему bd_shops (если не существует
2. Проверяет наличие функции calc_shop_efficiency(), создает при необходимости
3. Собирает статистику по данным (количество магазинов, сотрудников, посещений)
4. Создает таблицу bd_shops.shop_efficiency с результатами расчета
5. Выводит распределение по рейтингам и топ-3 магазина

#### 3️⃣ **log_success** — Логирование результатов
**Назначение:** Сбор статистики и вывод итогового отчета

**Информация в логах:**
```text
 ✅ Статус выполнения
 📊 Количество загруженных записей
 📈 Общее количество магазинов в БД
 📊 Количество записей в витрине
 ⏰ Дата выполнения и ID запуска
```
